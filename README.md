## 2. สำรองข้อมูล (ทำครั้งเดียว แล้วระบบทำต่อเอง)

```bash
curl -fsSL -o /root/ikssa_backup.sh https://raw.githubusercontent.com/iksonlinemkt/iks-corporate/ikssa-deploy/ikssa_backup.sh
bash /root/ikssa_backup.sh --auto      # สำรองทันที + ตั้งสำรองอัตโนมัติทุกวันตี 3
bash /root/ikssa_backup.sh --list      # ดูชุดที่มี
```

- ทุกวันตี 3: ฐานข้อมูล + ตั้งค่า + โค้ดเว็บ (เก็บ 14 วัน) · วันอาทิตย์เก็บรูปด้วย
- **ทุกครั้งที่ติดตั้งเว็บเวอร์ชันใหม่ (v40 ขึ้นไป) ระบบสำรองก่อนอัตโนมัติ** ถ้าสำรองไม่ได้ จะไม่ยอมติดตั้ง
- เก็บนอกเซิร์ฟเวอร์อีกชั้น (กันเครื่องเสีย): เปิด **Snapshot/Backup ใน hPanel ของ Hostinger** และ/หรือดาวน์โหลดชุดล่าสุดมาเก็บที่คอม (PowerShell บน Windows):
  ```powershell
  scp -r root@187.127.108.153:/root/backups/ikssa/latest ./ikssa-backup
  ```

## 3. ไม่ชอบสิ่งที่แก้ → ย้อนกลับ

| ต้องการ | คำสั่ง |
|---|---|
| หน้าตา/ฟีเจอร์กลับเป็นก่อนติดตั้งครั้งล่าสุด (ข้อมูลหลังบ้านไม่ถูกแตะ) | `bash /root/ikssa_backup.sh --restore-app <ชื่อชุด pre-install>` |
| ข้อมูลหลังบ้านกลับเป็นของวันนั้น | `bash /root/ikssa_backup.sh --restore-db <ชื่อชุด>` |
| รูปกลับเป็นของวันนั้น | `bash /root/ikssa_backup.sh --restore-media <ชื่อชุด +รูป>` |
| ติดตั้งเวอร์ชันเก่าซ้ำจาก GitHub | `ikssa_web_vNN.sh` ใน branch `ikssa-deploy` |

ทุกคำสั่งกู้ จะสำรองสถานะปัจจุบันก่อนเสมอ (ชุด `pre-restore`) จึงย้อนการกู้ได้อีกที และต้องพิมพ์ `YES` ยืนยัน

## 4. กติกาการแก้ไข (สำหรับคนและ AI ที่มาแก้ต่อ)

1. **แก้เฉพาะจุดที่ขอ** — ไม่ปรับดีไซน์ สี ฟอนต์ ลำดับเมนู หรือโครงหน้าส่วนอื่นเอง ถ้าเห็นว่าควรปรับ ให้ "เสนอ" แยก แล้วรอคำตอบ
2. **การเปลี่ยนใหญ่ต้องถามก่อน**: ลบ/ย้ายหน้า เปลี่ยนดีไซน์ภาพปก เปลี่ยนเมนู เปลี่ยนโดเมน เปลี่ยนวิธีจองนัด
3. **ข้อมูลที่ทีมแก้ในหลังบ้านห้ามถูกทับ** — migration ต้องรันซ้ำได้ และอัปเดตข้อมูลเฉพาะ "เมื่อยังเป็นค่าเดิม/ค่าตัวอย่าง" (`where value = '<ค่าเดิม>'`)
4. **ทุกการแก้ = เวอร์ชันใหม่** (v41, v42, …): commit ชื่อ `vNN: …` ใน `ikssa-source` + ตัวติดตั้งใน `ikssa-deploy` + บันทึกใน `CHANGELOG.md` ว่าแก้อะไร
5. ทดสอบก่อนส่ง (build, รัน migration 2 รอบ, ดูหน้าจอคอมและมือถือ) และบอกตรง ๆ ว่าส่วนไหนยังไม่ได้ทดสอบกับของจริง
6. สร้างตัวติดตั้ง: `bash deploy/build_package.sh v41`
